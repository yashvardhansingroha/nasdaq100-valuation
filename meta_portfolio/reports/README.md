# Investment Memo (Markdown Companion)

The interviewer-facing PDF is generated by:

```bash
python -m meta_portfolio
```

→ `meta_portfolio/reports/allocation_memo.pdf`

This markdown mirrors the memo structure so you can edit narrative offline. Numbers in the PDF are filled live from the backtest.

## Structure

1. Executive Summary  
2. Investment Thesis  
3. Strategy Sleeves — see [STRATEGY_RATIONALE.md](STRATEGY_RATIONALE.md)  
4. Methodology — 60-day risk, InvVol / MinVar / MaxDiv, 10bps costs  
5. Results — Performance sheet in Excel + equity curve  
6. Regime Analysis — Regimes sheet + commentary  
7. Risks & Limitations  
8. Conclusion — mandate-dependent recommendation
