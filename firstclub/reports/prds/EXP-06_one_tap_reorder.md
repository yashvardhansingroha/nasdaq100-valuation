# PRD: EXP-06 — One-Tap Reorder Carousel on Home

**Status:** Ready for A/B | **ICE:** 7.3 | **Effort:** 2 weeks

## Problem
Repeat purchase requires full browse flow. Friction reduces 14-day repeat rate.

## Solution
Home screen carousel: last 5 purchased items with single-tap "Reorder all" CTA.

## Success Metrics
- **Primary:** Repeat order rate 14d (+10%)
- **Guardrail:** Home screen load time (<1.5s)

## Scope
- Order history API (last 5 unique SKUs)
- Carousel component on home
- One-tap add all to cart

## Out of Scope
- Smart substitutions for OOS items
- Cross-sell recommendations
