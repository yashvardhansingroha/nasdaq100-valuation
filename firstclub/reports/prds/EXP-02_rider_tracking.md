# PRD: EXP-02 — Live Rider Photo + Order Tracking v2

**Status:** Ready for A/B | **ICE:** 6.7 | **Effort:** 4 weeks

## Problem
48% of trust-themed reviews are negative. "Where is my order?" drives support volume post-checkout.

## Solution
Post-payment: rider name, photo, vehicle, live map. Push on rider assignment and 2-min-away.

## Success Metrics
- **Primary:** D7 retention (+5%)
- **Guardrail:** CSAT post-delivery (>4.2)

## Scope
- Rider profile API integration
- Map SDK (Google/Mappls)
- Push notification triggers

## Out of Scope
- In-app chat with rider
- Tip/rating before delivery
