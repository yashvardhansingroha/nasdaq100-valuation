# FirstClub — Install-to-First-Order Funnel Teardown

End-to-end product teardown of FirstClub's install-to-first-order funnel: App Store review synthesis, 1.2M+ order dataset analysis, competitive benchmarks, 8 ICE-scored growth experiments, CAC/LTV simulator at 1M-order scale, and growth deliverables (30-60-90 roadmap, mini PRDs, event taxonomy, city launch playbook).

## Quick Start

```bash
# Install root dependencies (includes streamlit, plotly, pyarrow)
pip install -r requirements.txt

# Generate synthetic datasets + run full analytics pipeline
python -m firstclub

# Force regenerate 1.2M order dataset
python -m firstclub --force

# Launch interactive dashboard
streamlit run dashboard/firstclub.py
```

## Pipeline Outputs (`output/`)

Generated by `python -m firstclub`:

- `funnel_conversion.csv` — stage-by-stage install → first order
- `funnel_by_city.csv` / `funnel_by_channel.csv` — dimensional cuts
- `review_themes.csv` — App Store sentiment by theme
- `competitive_benchmarks.csv` — Blinkit / Zepto / Instamart / BigBasket Now
- `experiments_ice.csv` — 8 ICE-scored growth experiments
- `ltv_scenarios.csv` — CAC/LTV at 1M-order scale under experiment uplifts

## Data Note

Order and review data are **synthetic but statistically representative** of a 1.2M+ order quick-commerce warehouse. Metrics are calibrated to public competitive benchmarks and review themes; replace `data/orders.parquet` with production extracts for live analysis.
